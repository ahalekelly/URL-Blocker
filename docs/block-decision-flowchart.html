Does URL Blocker block this page?

The check every navigation runs through. A page is blocked only when it matches an enabled entry and a schedule or time limit is active right now. The right-hand lane is the express path for a direct match.

Root-URL expansion (the middle chain) is what blocks a site’s feed — landing on reddit.com — while still letting you open a specific link into it. It only fires for a bare-domain “URL” entry, and only on a qualifying arrival, governed per domain by the block direct visits and block internal links toggles. A direct match to a more specific entry (full path, subpaths, or regex) takes the express lane straight to the activation gate.

Arrival memory. Each page’s arrival referrer is recorded in extension storage for 30 days, so Back/Forward returns and periodic re-checks re-apply the arrival that originally brought you to the page — the browser’s own referrer goes stale on SPAs, where every in-app hop keeps the document’s first referrer. A history return whose arrival can’t be determined (no record, expired record, or unreadable storage) counts as a qualifying arrival, so it blocks rather than slips through.
